# Dell G15 5511 – PC Hardware Passport

## 1. Project Overview

The PC Hardware Passport is a practical assignment designed to explore computer hardware, understand system specifications, and observe how a computer works.

This repository contains my Day 1 assignment, completed using my Dell G15 5511 laptop.

## 3. Day 1 – Tasks Performed

### Task 1: System Information and Hardware Specifications

Collected and documented the basic hardware specifications of my laptop.

This includes the processor, installed RAM, graphics card, storage capacity, and system type.

**File:** `day1_specs.txt`

### Task 2: File Save Journey

Explored the process of saving a file on the computer and documented the journey of the file through the system.

**File:** `file_save_journey.png`

### Task 3: System Performance and Component Inventory

Observed system resource usage in two conditions:

- **Idle Reading:** Recorded system performance when the laptop was not performing heavy tasks.
- **Load Reading:** Recorded system performance while the laptop was under workload.

Also documented the hardware components in the component inventory.

**Files:**
- `idle_reading (2).png`
- `load_reading.png`
- `component_inventory.xlsx`

## 4. Learning Outcomes

Through this assignment, I learned:

- How to check and document laptop specifications.
- About the basic hardware components of a computer.
- How a file-saving process works.
- How to observe system performance during idle and load conditions.
- How to prepare a hardware component inventory.
